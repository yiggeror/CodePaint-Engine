# 扩展路线

本仓库定位为通用动画引擎；已有程序化油画技术是第一批可用能力。

## 当前完成

- 通用时间驱动器、二维/三维相机和速度映射。
- 可插拔渲染接口，平面图形后端与程序化油画后端。
- 从 Rainroji 第二部继承的笔触光栅器、三维笔触世界及光照插值。
- 基础音频工具、视频导出、可运行示例和自动测试。
- 中文架构、技术栈、来源、制作流程及维护说明。

## 下一批优先

1. **统一工程配置**：新短片可用简短配置声明尺寸、帧率、场景入口、素材路径和渲染质量。
2. **预览与审查工具**：自动生成静帧联系表、短片段、首尾和转场检查清单。
3. **场景组件化**：把人物 IK、植被、河水、天气、粒子、阴影等从原片拆成独立可选模块。
4. **分段并行与缓存**：提供统一的分段调度，保持不同机器和不同片段的一致输出。
5. **完整音画时间线**：从基础音轨放置提升到按角色动作、相机位置和环境状态驱动的音效编排。

## 更远期

- 像素、矢量、水墨、剪纸、非真实感三维等独立风格后端。
- 浏览器 Canvas、WebGL 或其他交互运行时。
- 角色动画、镜头预演、材质、后期特效和多轨合成系统。
- 可视化编辑工具、规范化项目模板和自动质量检查。

每项扩展先由真实短片验证，再变为稳定公共模块，持续积累技术能力。
